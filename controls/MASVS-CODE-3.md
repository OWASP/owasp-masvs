# MASVS-KÓD-3

## Ovládání

Aplikace používá pouze softwarové komponenty bez známých zranitelností.

## Popis

Aby byla skutečně bezpečná, mělo být u všech komponent aplikace prokázánaaeno úplné posouzení whiteboxu. Nicméně, jak se to obvykle stává u např. Pro komponenty třetích stran to není vždy proveditelné a není typicky součástí penetračního testu. Tento ovládací prvek pokrývá případy, nízko vizícího ovoce, jako jsou ty, které lze detekovat pouhým skenováním známých v knihovnách.
